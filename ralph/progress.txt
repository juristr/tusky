# Ralph Progress Log - Login Feature

## Codebase Patterns
- Fastify plugins use `fastify-plugin` (fp) wrapper - see sensible.ts pattern
- Plugins are auto-loaded from apps/api/src/app/plugins/ via @fastify/autoload
- AUTH_COOKIE_NAME = 'tusky_session' - use this constant for auth cookie
- Backend libs use dist/ exports (not src/) - check api-ratings/package.json pattern
- Module augmentation for fastify types requires import of .d.ts file (import '../types/fastify-cookie.js')
- Backend libs need `emitDeclarationOnly: false` in tsconfig.lib.json for JS output
